# 妖怪ウォッチ2 全妖怪言えるかな？

妖怪の名前を入力して一覧を埋めるブラウザーゲームです。

- 基本：398体
- ボスあり：448体
- ボス＆指名手配妖怪あり：516体
- 正式名称・ひらがな・カタカナに対応
- 正解数・経過時間・一時停止・途中保存・結果のツイートに対応

## GitHub Pagesで公開する手順

1. GitHubで新しい公開リポジトリ（Public）を作成します。リポジトリ名は自由です。
2. このZIPを展開し、中の7ファイルをリポジトリの一番上へアップロードしてコミットします。ZIPそのものをアップロードするのではなく、展開したファイルをアップロードしてください。`index.html`が一番上に置かれる形です。
3. リポジトリの`Settings`→`Pages`を開きます。
4. `Build and deployment`の`Source`を`Deploy from a branch`にします。
5. `Branch`を`main`、フォルダーを`/(root)`にして`Save`します。
6. 公開が完了すると、Pages画面に表示されるURLで遊べます。

参照：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## ファイル構成

- `index.html`：画面
- `style.css`：レイアウトと色
- `game.js`：ゲームの動作
- `share.js`：結果のツイート文とXの投稿画面へのリンク
- `data.js`：妖怪の名前・読み・画像
- `.nojekyll`：GitHub Pagesの設定用空ファイル
- `README.md`：この説明書

画像は`data.js`に同梱済みです。画像フォルダーの追加アップロード、サーバー、APIキー、ビルド作業は不要です。通常のリポジトリのサブフォルダー形式のURLでも動作します。

## ツイート文

例：

> 「妖怪ウォッチ2 全妖怪言えるかな？」に挑戦！
> 321/448体の妖怪を思い出せた！
> 難易度：ボスあり｜タイム：00:25:18
> #妖怪ウォッチ2 #全妖怪言えるかな
> 公開ページのURL

回答数・難易度・タイムは結果から自動で入ります。全問正解時は2行目が「448/448体、全妖怪コンプリート！」のように変わります。

「結果をツイート」を押すと、文章を入力済みのX投稿画面が別タブで開きます。投稿は利用者がX側で行います。公開ページのURLは自動で取得するので、GitHubのユーザー名やリポジトリ名をコードに書く必要はありません。

文面を変える場合は`share.js`の`resultTweetText`を編集してください。

## 手元で確認する

`index.html`をブラウザーで開いて確認できます。ローカルファイルからの確認中はツイート文に公開URLが入りません。GitHub Pagesで公開してから確認してください。

進み具合は利用者のブラウザーに保存されます。ブラウザーや公開先が変わると、保存される場所も変わります。

妖怪ウォッチ2の非公式ファンゲームです。株式会社レベルファイブとは関係ありません。
